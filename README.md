# 自动获取指定账户喜欢的X帖子并进行推送

## 场景需求
自动获取目标用户（一般是自己）喜欢的帖子，从首次运行开始，每有新喜欢的图片帖子，使用Telegram Bot全自动发送图片和链接到指定频道，免去了手动保存图片与链接的麻烦.

## 使用方法
使用你喜欢的方法获取本仓库内容，确保本地安装了*Python 3.10.10*及更新版本，执行`pip install -r requirements.txt`安装依赖.

`main.py` 各项参数说明如下：

|        参数        |   参考值   |            说明            |
| :--------------------: | :-----: | :--------------------------: |
| userid | 114514 |    在目标用户主页，获取 banner 图片链接中的用户 ID |
| bottoken  |  114514:ABCDEFG | Telegram Bot 的 token，直接写在 `main.py` 中 |
| chatid  | -114514 |    Bot 发送的聊天 ID |
| sleeptime  | 86400  |    睡眠时间，单位为秒 |
| cookies  |         `ct0`、`auth_token`  |    X Cookie，直接写在 `main.py` 中 |
| max_like_pages | 5 | Likes 最大翻页数 |
| like_page_size | 40 | 每页获取数量，范围 1-100 |

Likes 请求默认每页 40 条、最多 5 页；翻页过程中一旦整页内容都已在去重记录中，会提前停止请求。临时的 `DeadlineExceeded` 会自动重试；后续页面持续失败时保留已成功页面，首次初始化获取不完整时不会写入状态。

Telegram 推送对网络异常、5xx 和 429 限流自动重试（429 按 `retry_after` 等待），确定性失败（如图片超过 5MB）不重试，留待下一轮。
